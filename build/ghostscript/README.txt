║        Ghostscript — підготовка до збірки інсталятора        ║
╚══════════════════════════════════════════════════════════════╝

Ghostscript не може бути завантажений автоматично під час збірки,
оскільки його ліцензія (AGPL) вимагає ручного підтвердження умов.

Виконайте наступні кроки:

───────────────────────────────────────────────────────────────
Крок 1. Завантажте Ghostscript 10.x для Windows 64-bit

  https://ghostscript.com/releases/

  Файл: gs10xx_w64.exe  (наприклад gs10040_w64.exe)

───────────────────────────────────────────────────────────────
Крок 2. Встановіть Ghostscript на цьому комп'ютері

  Запустіть інсталятор, погодьтеся з умовами ліцензії.
  Стандартний шлях установки:
    C:\Program Files\gs\gs10.x.x\

───────────────────────────────────────────────────────────────
Крок 3. Скопіюйте вміст папки gs10.x.x\ сюди

  Джерело:    C:\Program Files\gs\gs10.x.x\
  Призначення: (ця папка — build\ghostscript\)

  Після копіювання у цій папці мають з'явитися підпапки:
    bin\        ← містить gswin64c.exe
    lib\        ← PostScript файли ресурсів
    Resource\   ← шрифти та кольорові профілі GS
    iccprofiles\ ← ICC-профілі Ghostscript

  Перевірити: build\ghostscript\bin\gswin64c.exe має існувати.

───────────────────────────────────────────────────────────────
Крок 4. Запустіть збірку

  Поверніться у папку build\ та запустіть:
    build_all.bat

  Або спочатку перевірте всі інструменти:
    check_tools.bat

───────────────────────────────────────────────────────────────
