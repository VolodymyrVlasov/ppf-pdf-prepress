# PDF Pre-Press Processor

Інструмент для підготовки PDF-файлів до друку.  
Підтримує конвертацію у CMYK / Grayscale та перспективну деформацію сторінок.  
Має живий попередній перегляд деформації та інтеграцію з контекстним меню Windows.

---

## Вимоги

| Компонент | Версія | Обов'язково |
| --- | --- | --- |
| Python | 3.11+ | Так |
| pip-залежності | див. `requirements.txt` | Так |
| Ghostscript | будь-яка актуальна | Ні (покращує точність кольору) |

> **Ghostscript** встановлюється окремо з [ghostscript.com](https://www.ghostscript.com/releases/gsdnld.html).  
> Без нього програма працює через Pillow — результат трохи відрізняється від поліграфічного стандарту.

---

## Встановлення

### 1. Встановіть Python 3.11+

Завантажте з [python.org](https://www.python.org/downloads/).  
При встановленні увімкніть галочку **"Add Python to PATH"**.

### 2. Встановіть залежності

```bat
install.bat
```

або вручну в папці проєкту:

```bat
pip install -r requirements.txt
```

### 3. (Необов'язково) Додайте ICC-профіль

Для поліграфічно точної конвертації в CMYK покладіть файл  
`ISOcoated_v2_eci.icc` поряд із `processor.py`.  
Профіль доступний безкоштовно на [eci.org](http://www.eci.org/en/downloads).  
Без профілю виконується пряма конвертація засобами Pillow.

## Запуск

### Безпосередньо через Python

```bat
python main.py
```

Відкриється діалог вибору PDF-файлу, після якого запустяться налаштування.

```bat
python main.py "C:\Documents\file.pdf"
```

Відразу відкриває вікно налаштувань для вказаного файлу.

### Через .exe (після збирання)

```bat
build.bat
```

Після збирання:

```bat
%USERPROFILE%\pdf_prepress\pdf_prepress.exe
%USERPROFILE%\pdf_prepress\pdf_prepress.exe "C:\Documents\file.pdf"
```

---

## Збирання .exe

1. Переконайтесь, що PyInstaller встановлений (`pip install pyinstaller`)
2. **(Необов'язково)** Покладіть `icon.ico` поряд із `build.bat`  
   (без іконки програма збереться зі стандартною іконкою Python)
3. Запустіть:

```bat
build.bat
```

Скрипт:

- Зберить `pdf_prepress.exe` за допомогою PyInstaller
- Скопіює його до `%USERPROFILE%\pdf_prepress\`
- Виведе інструкцію щодо встановлення контекстного меню

### Про icon.ico

Файл `icon.ico` не входить до репозиторію. Створіть власну іконку або  
конвертуйте будь-яке зображення `.png` у `.ico` за допомогою онлайн-сервісів  
(наприклад, [convertio.co](https://convertio.co/png-ico/)).  
Розмір: рекомендується 256×256 пікселів.

## Інтеграція з контекстним меню Windows 10/11

Після збирання .exe можна клацати правою кнопкою на будь-якому .pdf  
і одразу відкривати програму.

### Встановлення пункту меню

1. Відкрийте папку `context_menu\`
2. Двічі клацніть `install_context_menu.reg`
3. Підтвердіть імпорт у реєстр

Після цього у контекстному меню .pdf-файлів з'явиться:  
**PDF Pre-Press → Відкрити налаштування**

> **Шлях за замовчуванням:** `%USERPROFILE%\pdf_prepress\pdf_prepress.exe`  
> Якщо ви скопіювали .exe в інше місце — відредагуйте `install_context_menu.reg`  
> перед імпортом: знайдіть рядок з `pdf_prepress.exe` і замініть шлях.

### Видалення пункту меню

Двічі клацніть `context_menu\remove_context_menu.reg` і підтвердьте.

## Можливості

| Режим | Опис |
| --- | --- |
| CMYK | Конвертація кольорів RGB → CMYK |
| Grayscale | Конвертація у відтінки сірого |
| CMYK + деформація | CMYK + перспективна деформація сторінок |
| Grayscale + деформація | Grayscale + перспективна деформація сторінок |

### Деформація сторінок (Warp)

Дозволяє компенсувати геометричні спотворення друкарської машини.  
Окремі налаштування для непарних (FRONT) і парних (BACK) сторінок.  
Зміщення задається у міліметрах для кожного з чотирьох кутів.  
Живий попередній перегляд оновлюється в реальному часі при введенні значень.

## Налаштування

Зберігаються у `settings.json` (поряд із `main.py`) автоматично при запуску обробки.

```json
{
  "dpi": 300,
  "odd_corners":  { "tl": [0,0], "tr": [0,0], "bl": [0,0], "br": [0,0] },
  "even_corners": { "tl": [0,0], "tr": [0,0], "bl": [0,0], "br": [0,0] },
  "output_suffix_cmyk": "_CMYK",
  "output_suffix_gray": "_GRAY"
}
```

Вихідні файли зберігаються поряд із оригіналом із суфіксом у назві:  
`document.pdf` → `document_CMYK.pdf`

## Структура проєкту

```text
pdf_prepress/
  main.py                          — точка входу, обробка аргументів CLI
  gui.py                           — вікно налаштувань (SettingsWindow + WarpPreviewCanvas)
  processor.py                     — ядро обробки зображень
  settings.py                      — завантаження / збереження settings.json
  requirements.txt                 — залежності pip
  install.bat                      — встановлення залежностей
  build.bat                        — збирання .exe через PyInstaller
  icon.ico                         — іконка програми (додайте самостійно)
  context_menu/
    install_context_menu.reg       — додає пункт у контекстне меню .pdf
    remove_context_menu.reg        — видаляє пункт із контекстного меню
  README.md                        — ця документація
```
